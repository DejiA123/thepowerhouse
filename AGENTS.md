# Technical decisions

- Vite `build.target` must be the single string `'es2020'`, never a multi-engine list like `['es2020', 'safari14']`: esbuild 0.27.2's transform API falsely reports destructuring as unsupported when the target list contains multiple engines (fixed by Grafana et al. in esbuild 0.27.5+). If esbuild is ever upgraded past 0.27.2, a list can be restored if needed.
- Keep the `es2020` floor (Safari 14+): many members use older iPhones, so do not raise the build target above it.
- The read-aloud Bible voice (non-narrated translations) runs only in the cloud (`bible-tts` edge function → Lovable AI speech, WAV → MP3 in `aiVoice/encoder.worker.ts`); the ~290 MB on-device model froze phones and was removed. Offline listening = chapters kept on the device (heard, or saved per book in Listen offline). Don't call it "AI voice" anywhere members can see.
- Next/previous chapter logic lives in `services/audioBible/nextChapter.ts` (fuzzy book-name matching, tested); the player prefetches the next chapter's playable link so auto-advance starts with no awaits (phones block delayed background play).
- Installing: `lib/install.ts` (device detection, Android's install offer caught at startup) + `components/install/` (Home card, step-by-step guide). `public/install/ThePowerHouse.mobileconfig` is an iPhone profile that adds the app to the Home Screen; remake it with `scripts/make-install-profile.py`.
- Church Space (one app for many churches): everything specific to a church — name, logo, colours, links, contacts, campuses, giving details, live times, choir branches, Home banners and which parts of the app it uses — lives in `src/config/church.ts` (the server functions' copy: `supabase/functions/_shared/church.ts`). Never hard-code a church's details anywhere else. Parts a church can switch off are tagged `feature` in `src/data/appDirectory.ts`, and their pages are guarded by `src/components/FeatureGate.tsx`. index.html (`%CHURCH_…%`) and manifest.json are made from the profile at build time (`src/config/brandFiles.ts` + the `churchBrand` plugin in vite.config.ts), so editing the profile restarts the dev server.
