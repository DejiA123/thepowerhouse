📖 Auto-Play Next Chapter - FIXED

Bible audio now automatically advances to the next chapter and continues reading

❌ Problem Before Fix

  • • Audio would finish reading a chapter but not advance to the next
  • • User had to manually navigate to next chapter every time
  • • Auto-Play Next Chapter setting was not working properly
  • • Interrupting reading experience

✅ Solution Implemented

  • • Fixed auto-play logic to use current audioState instead of stale parameters
  • • Audio automatically advances to next chapter after finishing current one
  • • Automatically starts reading the next chapter without user intervention
  • • Seamless continuous Bible reading experience

🔧 Technical Fix Details

Root Cause:

The `utterance.onend` handlers were checking the `autoPlayNext` parameter from the function scope instead of the current `audioState.autoPlayNext` value. Since the onend callback executes later when audio finishes, it was using stale/incorrect values.

❌ Before (Broken Code):

utterance.onend = () => {
  // Auto-play next chapter if enabled
  if (autoPlayNext) { // ❌ Uses stale parameter!
    const next = getNextBookAndChapter(book, chapter);
    // ... rest of logic
  }
};

✅ After (Fixed Code):

utterance.onend = () => {
  setAudioState(prev => {
    // Auto-play next chapter if enabled (use current state)
    if (prev.autoPlayNext) { // ✅ Uses current state!
      const next = getNextBookAndChapter(book, chapter);
      if (next) {
        // Update UI and schedule next chapter
        if (next.book !== book) {
          bookChangeCallbackRef.current?.(next.book, next.chapter, true);
        } else {
          chapterChangeCallbackRef.current?.(next.chapter, true);
        }
        
        // Auto-play next chapter after 2 second delay
        autoPlayTimeoutRef.current = setTimeout(() => {
          loadAndPlayChapter(next.book, next.chapter, true, voiceSettings, 'kjv');
        }, 2000);
      }
    }
    
    return { ...prev, isPlaying: false, isPaused: false, isLoading: false };
  });
};
