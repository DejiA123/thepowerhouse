🔄 How Loop Chapter Works

1 Normal Flow (Loop OFF)

Start reading Genesis 1
Chapter finishes
Auto-advance to Genesis 2
Continue to Genesis 3, 4, 5...

2 Loop Flow (Loop ON)

Start reading Genesis 1
Chapter finishes
2 second pause
🔄 Restart Genesis 1
🔄 Repeat indefinitely...

🎚️ Priority Logic

1
Loop Chapter (Highest Priority)
2
Auto-Play Next Chapter (Only if Loop is OFF)
3
Stop (If both are OFF)

Smart Logic: If Loop Chapter is ON, it takes priority and Auto-Play Next Chapter is ignored. This prevents conflicts and ensures predictable behavior.
